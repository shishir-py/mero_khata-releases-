# Mero Khata (मेरो खाता) — downloads

APK downloads for **Mero Khata**, a private, offline-only expense tracker for Android 8.0+.
It turns bank SMS (Global IME, Nabil, MBL and others) into transactions you review, shows dates in
Bikram Sambat, and keeps everything in an encrypted database on your phone. No account, no server,
no internet permission.

## Download

Open **[Releases](../../releases)** and pick one APK:

- **MeroKhata-Lite-x.y.z.apk**: no SMS permission. Add bank messages with *Share → Add to Mero Khata*
  or by pasting them. Use this one if Play Protect blocks the full version.
- **MeroKhata-x.y.z.apk**: reads bank SMS automatically.

Both are the same app with the same signature, so you can switch between them and keep your data.
`SHA256SUMS.txt` lets you check the download.

## Installing

Android warns about apps from outside the Play Store. Allow your browser or file manager to
"install unknown apps". If Play Protect says the app is blocked, choose **More details → Install anyway**,
or install the Lite APK.

## Keep a backup

Turn on **Settings → Backup → Automatic backup** and choose a folder that is synced or copied off the phone.
Backups are encrypted with your backup password. Without that password they cannot be restored.
